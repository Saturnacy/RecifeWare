# RecifeWare

Série de minigames inspirada na cultura de Recife, baseada no estilo WarioWare.

## Como compilar e rodar

**Requisitos:** `gcc` e `make`

```bash
make run
```

Isso compila o projeto e abre o jogo. O executável fica em `build/RecifeWare` (Linux) ou `build/RecifeWare.exe` (Windows).

Para apenas compilar sem rodar:

```bash
make
```

Para limpar os arquivos compilados:

```bash
make clean
```
